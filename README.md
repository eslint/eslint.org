# The New eslint.org

This repository contains the source code for the ESLint website (<https://eslint.org>).

## Developer Setup

In order to run the website, you must have [Node.js](https://nodejs.org) installed.

1. Create a fork of the repository
2. Run `npm install`

To start a local copy of the website, run:

```shell
npm start
```

The website is built with [Astro](https://astro.build) and is available at <http://localhost:2022> while the development server is running. To create a production build of the website in the `dist` directory, run:

```shell
npm run build
```

English pages are published at the root of the website and translated pages are published under their language code. For example, the Spanish homepage is available at <http://localhost:2022/es/>.

## Translations

If you'd like to add a new translation of this website, please [open an issue](https://github.com/eslint/eslint.org/issues/new/choose) first.

All of the text on the website lives in the site files in `src/i18n`, one for each language. Each site file is a locale in [Astro's internationalization support](https://docs.astro.build/en/guides/internationalization/), and pages and components retrieve the text for the current locale with `getSite(Astro.currentLocale)` from `src/lib/site.ts`. Text that is missing from a translation falls back to English.

The homepage and the branding, donate, languages, sponsors, and team pages are translated (see `src/pages/[...locale]`). Everything else, such as the blog and the playground, only exists in English.

In order to create a new translation:

1. Copy the `src/i18n/en.yml` file to a new site file in the same directory. The filename should be the language code of the language you want to translate into. For example, if you want to translate into Spanish, you should create the file `src/i18n/es.yml` because "es" in the Spanish language code.
2. Translate the text in the new site file to your chosen language.
3. Test it locally to ensure that it works properly using the instructions in the previous section.
4. Submit your pull request

The new translation is published under its language code as soon as the site file is merged. The settings for the whole website (such as the hostname, analytics, and ads) always come from `src/i18n/en.yml`.
