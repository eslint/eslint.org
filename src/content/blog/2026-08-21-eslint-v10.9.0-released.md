## Highlights

### New option `checkConditionalExpressions` in `no-unmodified-loop-condition`

The [`no-unmodified-loop-condition`](/docs/latest/rules/no-unmodified-loop-condition) rule now supports a `checkConditionalExpressions` option.
When enabled, each branch in a ternary expression is checked independently.

For example, with `{ "checkConditionalExpressions": true }`, the rule reports the `done` variable as not modified in the loop:

```js
let chunk = getInitialChunk();
let done = false;

while (chunk ? !done : false) {
    chunk = nextOrNull();
}
```
