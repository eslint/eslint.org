There are three variations of a profile component on the site: the member, the contributor, and the post author.

The properties required for each are shown in the following example:

```astro
---
// first import the profile components
import PostAuthor from "../components/PostAuthor.astro";
import ProfileContributor from "../components/ProfileContributor.astro";
import ProfileMember from "../components/ProfileMember.astro";
---

<!-- then use a component -->
<ProfileMember
    name="Name LastName"
    handle="username"
    bio="This is a member's biography. An example of a member is a team member on the team page."
    twitter="twitterUsername"
    github="githubUsername"
/>

<ProfileContributor name="Contributor Name" handle="myHandle" />

<PostAuthor
    name="Nicholas Zakas"
    title="Creator of a popular framework"
    handle="nzakas"
    twitter="twitterHandle"
    github="githubHandle"
/>
```
